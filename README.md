# Global-Superstore-Sales-Analytics-Dashboard---Power-BI

## Overview

An interactive **Power BI dashboard** built using the Global Superstore dataset to analyze sales, profit, customers, products, and regional performance.

## Key Features

- 📈 Sales and profit analysis
- 💰 KPI tracking
- 🛒 Order and customer analysis
- 📦 Top-selling products
- 🌍 Geographic sales analysis
- 📊 Category and segment performance
- 🎯 Sales, profit, and margin targets
- 👥 Customer revenue analysis

## Key KPIs

- **Total Sales:** $12.64M
- **Total Profit:** $1.47M
- **Total Orders:** 25.04K
- **Total Customers:** 4,873
- **Profit Margin:** 11.61%
- **Average Order Value:** 501.63

## Tools Used

- **Power BI**
- **Power Query**
- **DAX**
- **Data Modeling**

## Dashboard Pages

1. **Executive Sales Overview**
2. **Sales & Profitability Analysis**
3. **Global Geographic Analysis**
4. **Customer Analysis**

## Objective

The goal of this project is to transform raw sales data into meaningful visual insights that help understand business performance and support data-driven decision making.
